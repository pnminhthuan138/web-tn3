Tạo trắc nghiệm từ ảnh / PDF

Không cần API key. Trang đọc chữ (OCR) ngay trên máy bạn, rồi tách thành câu hỏi trắc nghiệm có sẵn trong đề.

1. Tải file lên

Bấm để chọn file hoặc kéo thả vào đây
Ảnh, PDF, TXT, MD

2. Kiểm tra văn bản

OCR có thể đọc sai dấu hoặc ký tự. Hãy sửa trực tiếp tại đây, hoặc dán văn bản đề vào. Mỗi câu bắt đầu bằng "Câu 1." hoặc "1.", lựa chọn bắt đầu bằng A. B. C. D. Đáp án ghi dạng "Đáp án: B", hoặc đánh dấu * cạnh lựa chọn đúng, hoặc có bảng đáp án cuối đề (1-A 2-B …).
